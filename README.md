# Study Tips for Programming

## What
A beginner-friendly guide of study tips for learning programming.

## Why
Many beginners feel lost and don't know how to study code effectively. This guide collects simple, practical tips in one place.

## Study habits
- Practice coding every day
- Build small projects
- Take breaks to avoid burnout

## How
Our team adds sections through branches and pull requests, reviewing each other's work before merging.
